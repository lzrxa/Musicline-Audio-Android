音频截取 / 调整音量 / 格式转换

本地解码后处理；建议长音频先分段，避免内存压力。支持设备可解码的 MP3、WAV、M4A、OGG 等格式。

音量超过 0 dB 时进行削峰保护，避免数字削波。

多轨音频编辑器

移植自你原版的 SongEdit147 编辑器，支持波形、切分、混音等本地功能。部分高级功能依赖 OPFS、AudioWorklet 和设备浏览器能力，建议先处理短音频。

此模块属于实验性离线兼容：不同 Android WebView 可能无法使用其全部效果，音频输入与导出请先用短文件验证。

五大 MDX 模型 · 首次下载后离线可用

选择需要的模型，联网下载一次并保存在手机本地。之后切换模型不再重新下载；正常应用升级也不会删除模型。

🧪 本阶段接入 Android ONNX Runtime 实验性分离：仅 MDX Inst HQ3 和 MDX Vocal FT 支持 WAV 输入测试。Karaoke、Kim Vocal 2、MDX Main 仍可下载，但因模型参数尚未验证，暂不开放运行。未经真机验证，效果及稳定性尚不能保证。
